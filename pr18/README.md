# Контрольная работа №3 (практики 13–17)

Контрольная работа №3 — итог по практическим заданиям `pr13`–`pr17`.

## Что сделано
- PWA заметки с офлайн‑режимом (Service Worker + Cache Storage + localStorage).
- App Shell архитектура (динамическая подгрузка страниц из `content/*`, стратегия Network First).
- WebSocket‑события через Socket.IO (всплывающее уведомление о новой задаче в другой вкладке).
- Push‑уведомления (подписка/отписка, отправка уведомления с сервера).
- Напоминания (планирование уведомления на сервере через `setTimeout`) и действие «Отложить на 5 минут» из уведомления.

## Запуск
### pr16 (WebSocket + Push)
```bash
cd pr16
npm install
npm start
```
Открыть: `http://localhost:3001/`

### pr17 (Напоминания + Snooze)
```bash
cd pr17
npm install
npm start
```
Открыть: `http://localhost:3001/`

## Как проверить
1. Нажать «Включить уведомления» и разрешить уведомления в браузере.
2. Открыть 2 вкладки приложения: при добавлении заметки появится всплывающее сообщение.
3. В `pr17` добавить заметку с напоминанием: по наступлению времени придёт push, в уведомлении доступна кнопка «Отложить на 5 минут».
